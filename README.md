# AI-Powered Schedule Planner with Notion Integration

## 🚀 Overview
This project is a **web-based application** designed to help users generate customized schedules for their goals using the **OpenAI API**. The schedules are synced with the user's **Notion account**, allowing seamless tracking and progress management. Whether it’s planning a trip, meeting deadlines, or achieving personal milestones, this app provides an intelligent solution tailored to user inputs.

---

## ✨ Features
- **AI-Generated Schedules**: Leverages OpenAI API to create detailed, goal-oriented schedules.
- **Notion Integration**: Syncs schedules with the user's Notion workspace for real-time updates and management.
- **OAuth Authentication**: Ensures secure access using client ID and secret for user authorization.
- **Responsive Design**: Built with modern CSS techniques (flexbox, grid) for a smooth, cross-device experience.
- **Error-Resilient Merging**: Demonstrates a collaborative effort in resolving code integration issues under tight deadlines.

---

## 🛠️ Tech Stack
- **Backend**: Flask, Python, OpenAI API, OAuth 2.0
- **Frontend**: HTML5, CSS3, JavaScript
- **Libraries/Tools**: Jinja2, Requests, Notion API, Responsive Design with Flexbox & Grid
